# 🍗 疯四文学大合集（KFC Crazy Thursday Collections）

> 今天是疯狂星期四。全世界的快乐，汇编于此。

肯德基疯狂星期四（Crazy Thursday）——每周四，一场全民文学运动的发令枪。
绵长的铺垫、真挚的情感、猝不及防的转折，最终汇成那句共同的黑话：
**「谁请我吃？V 我 50。」**

本仓库是疯四梗文化的非官方大合集：文学文案、视频脚本、梗图模板、
资源导航，外加一个可以无限抽卡的**疯四文学生成器**。

## 🧭 疯四小史（三十秒版）

1. 肯德基推出「疯狂星期四」会员日：周四特惠，原价疯狂
2. 网友开始在社交媒体写「骗人读完全文」的小作文：前 90% 是任何故事，最后 10% 落到「今天是疯狂星期四，谁请我吃」
3. 文体自进化：悲情、科幻、武侠、论文、文言文……万物皆可疯四
4. 「V 我 50」（微信转我 50 元）成为固定收束句，周四是它的语法时态
5. KFC 官方下场玩梗，疯四文学完成从民间到庙堂的闭环
